# Data dictionary

Описание всех 30 таблиц базы smart_consumption.db (SQLite). 
Таблицы сгруппированы по источникам данных. Для каждой указаны тип, 
период, состав и ограничения.

База собрана из 8 источников: Chizhik + НИУ ВШЭ, Ромир, СберИндекс, 
Росстат, ВЦИОМ/Anketolog, НИУ ВШЭ (Барометр №2-2026), сводные 
источники по рынку FMCG (TAdviser/Data Insight/INFOLine), NielsenIQ. 
Первичные данные — в data/raw/умное_потребление_данные.xlsx.
---

## Chizhik + НИУ ВШЭ

### chizhik_index

Компоненты индекса умного потребления по 7 метрикам,
сопоставление 2024 и 2025 г.

| Колонка | Тип | Описание |
|---|---|---|
| metric | TEXT | Название метрики |
| value_2024 | REAL | Значение в 2024 г., % или п.п. |
| value_2025 | REAL | Значение в 2025 г., % или п.п. |
| unit | TEXT | Единица измерения |

**Источник:** НИУ ВШЭ + «Чижик» (X5), опрос >6000 респондентов 18+.
**Период:** 2024, 2025.
**Ограничения:** самоотчёт о ценностях, а не наблюдение поведения.
Единица измерения различается между метриками (%, п.п.),
поэтому прямое сравнение по абсолютному уровню некорректно —
только по динамике.

### chizhik_segments

Доли умных потребителей по демографическим сегментам.

| Колонка | Тип | Описание |
|---|---|---|
| dimension | TEXT | Разрез: Возраст, Пол, Семейное положение, Наличие детей, Тип населённого пункта, Импульсивность покупок, Канал покупки, Покупка новинок, Участие в распродажах |
| group | TEXT | Значение внутри разреза |
| smart_consumption_share_pct | REAL | Доля умных потребителей, % |
| period | TEXT | 2024 или 2025 |

**Источник:** тот же. **Период:** 2024, 2025.
**Ограничения:** пустые ячейки = показатель не публиковался
для этой волны. Размеры подгрупп не публикуются.

### chizhik_patterns

Поведенческие паттерны в парах групп (в браке vs одинокие,
с детьми vs без детей, женщины vs мужчины).

| Колонка | Тип | Описание |
|---|---|---|
| group_pair | TEXT | Название пары групп |
| metric | TEXT | Метрика поведения |
| value_group1 | REAL | Значение для первой группы, % |
| value_group2 | REAL | Значение для второй группы, % |

**Период:** 2024–2025.
**Ограничения:** значения приведены в процентах, но источник
не публикует размеры групп и p-value. Прямые сравнения
без статистики ограничены.

## Ромир

### consumer_confidence

Индекс потребительской уверенности (ИПУ) Ромир по возрастам
и размеру домохозяйства.

| Колонка | Тип | Описание |
|---|---|---|
| dimension_type | TEXT | Разрез: age_group или household_size |
| dimension_value | TEXT | Значение внутри разреза |
| index_value | INTEGER | Значение ИПУ |
| period | TEXT | Q1 2026 |
| source | TEXT | Ромир |

**Источник:** Ромир, Потребительская панель (через Retail.ru).
**Период:** Q1 2026.
**Ограничения:** ИПУ измеряет настроение, а не поведение.
Возрастные группы в ИПУ (18–24, 25–34, 35–44, 45–59, 60+)
не совпадают с группами Chizhik (25–34, 45–54, 55–64, 65+).
Прямое сопоставление между источниками некорректно.

### romir_confidence_dynamics

Динамика ИПУ Ромир по кварталам 2024–2025 гг. и отдельно 
по месяцам конца 2025 г. — в отличие от consumer_confidence, 
даёт временной ряд без разбивки по возрасту.

| Колонка | Тип | Описание |
|---|---|---|
| period | TEXT | Квартал/месяц |
| index_value | INTEGER | Значение ИПУ |
| sourse | TEXT |Ромир, декабрь 2025 |

**Источник:** Ромир, Индекс потребительской уверенности, 
декабрь 2025. 
**Период:** 2024 Q1 — 2025 Декабрь (12 точек, последние 4 — помесячно). 
**Ограничения:** часть значений (квартальные) и часть 
(помесячные за конец 2025 г.) — разная гранулярность внутри 
одной таблицы, не выстраиваются в единый равномерный временной 
ряд без дополнительной обработки. Используется в H2.R как 
дополнительный контекст (не часть основного теста H2): 
резкое падение ИПУ в окт-дек 2025 сопоставляется с плато 
поведенческого индикатора давления на бюджеты.

### stm_motivation

Мотивация выбора СТМ в 2022 г. — потенциальная база для 
сравнения с stm_motivation (2026).

| Колонка | Тип | Описание |
|---|---|---|
| factor_type | TEXT | Тип фактора |
| factor | TEXT | Название фактора |
| share_pct |  REAL | Доля респондентов, % |
| period | INTEGER | Год (2022) |
| sourse | TEXT |Ромир|

**Источник:** Ромир, «зафиксировал увеличение доли СТМ за 7 лет». 
**Период:** 2022. 
**Ограничения:** содержит только рациональные мотивы 
(цена, акции, запасы, новинки). Ценностных категорий 
(семья, безопасность, надёжность), которые есть в stm_motivation 
за 2026 г., в опросе 2022 г. не было — формулировки вопроса 
не совпадают. Не может использоваться как строгая базовая линия 
для проверки роста ценностных мотивов в H1, только как контекст 
с явной оговоркой о несопоставимости.

### stm_market_share

Доля СТМ на рынке — общая динамика 2015–2024 гг. и отдельные 
показатели по конкретным ритейлерам (Магнит).

| Колонка | Тип | Описание |
|---|---|---|
| year | INTEGER | Год |
| share_pct | REAL | Значение, % |
| metric | TEXT | Что именно измеряется |
| note | TEXT | Уточнение |
| sourse | TEXT | Ромир / TAdviser / NTech |

**Источник:** смешанный — Ромир (доля СТМ в деньгах 2015→2022), 
TAdviser (прирост доли в топ-10 ритейлеров 2023–2024), NTech 
(доля СТМ и СП в сетевой рознице 2024). 
**Период:** 2015–2024. 
**Ограничения:** строки относятся к разным метрикам 
(«доля рынка» vs «прирост доли» vs «доля у конкретного ритейлера»)
— нельзя читать как единый непрерывный временной ряд одного 
показателя, несмотря на общий столбец year.

## Общие оговорки

1. **Таблицы с суффиксом `_pct`** содержат доли в процентах,
   а не абсолютные значения.
